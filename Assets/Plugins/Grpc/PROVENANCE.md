# gRPC client libraries

Managed assemblies for マルチ演奏's connection to OurTaikoNet's room server
(`Assets/OurTaiko/Runtime/Multi`). Unmodified binaries from the NuGet packages named below, the
`netstandard2.1` build where the package has one, else `netstandard2.0`.

| File | Package | Version | License |
| --- | --- | --- | --- |
| `Google.Protobuf.dll` | Google.Protobuf | 3.36.2 | BSD-3-Clause |
| `Grpc.Core.Api.dll` | Grpc.Core.Api | 2.85.0 | Apache-2.0 |
| `Grpc.Net.Client.dll` | Grpc.Net.Client | 2.85.0 | Apache-2.0 |
| `Grpc.Net.Common.dll` | Grpc.Net.Common | 2.85.0 | Apache-2.0 |
| `System.IO.Pipelines.dll` | System.IO.Pipelines | 10.0.14 | MIT |

`Grpc.Net.Client` also needs `Microsoft.Extensions.Logging.Abstractions` and
`System.Diagnostics.DiagnosticSource`, which Unity 6000.6 provides itself.

HTTP/2 comes from YetAnotherHttpHandler (Cysharp, MIT), the UPM package
`com.cysharp.yetanotherhttphandler` 1.11.7 in `Packages/manifest.json`; it needs
`System.IO.Pipelines` and `System.Runtime.CompilerServices.Unsafe` (already in `Assets/Plugins`).

`Assets/OurTaiko/Runtime/Multi/Proto/Multiplay.cs` is generated by protoc 36.x from OurTaikoNet's
`proto/ourtaiko/multiplay/v1/multiplay.proto`:

    protoc --proto_path=proto --csharp_out=<game>/Assets/OurTaiko/Runtime/Multi/Proto proto/ourtaiko/multiplay/v1/multiplay.proto
